# MHR body model, subset for the V2D Challenge Track 1 metric

`v2d_track1_mhr.npz` is derived from MHR (Momentum Human Rig) lod1, `mhr_model.pt` from
https://github.com/facebookresearch/MHR (release v1.0.1, sha256 352e271a6c42729c68554ceaea0c955e866970160c31e35506d782dc0f7377bc),
Copyright (c) Meta Platforms, Inc. and affiliates, licensed under the Apache License 2.0
(`LICENSE.txt`).

Modified by NVIDIA for the V2D Challenge: the model's arrays were extracted to numpy, and the
skinning weights, identity blendshapes and pose-corrective output layer were restricted to the
603 vertices the Track 1 metric scores. The skeleton, parameter transform and inverse bind pose
are unchanged. The pose-corrective output weights are stored as float16. Generated by
`tools/build_mhr_asset.py`.
