## 1. Rules (read before starting)

- **No ground truth in any choice.** Seeds, meshes and runs are never picked by a score against
  ground truth or the scans. Public scores are computed only to report them.
- **Do not edit any file under `baseline/robotic_grounding/flash_chord/`** or the submission kit.
  The evaluator hashes its own code (`eval_code_sha256`); a different hash makes our runs and
  yours impossible to submit together.
- **Exact names**: episode folders `episode_XXXXXX` (6 digits), object folders exactly as in
  `tools/track3/episodes.json` (`white_pot`, `mini_dust_pan`, ...). The tools find files by path.
- **No gsplat refinement** in reconstruction (it jitters the camera; we score unrefined bundles).
- One GPU per training run. Do not run two trainings on the same GPU.
- If a step fails for one episode, log it (section 9) and continue with the others.

## 5. The training queue

`tools/track3/jobs/gpu_queue.sh` runs one worker per GPU. Each worker takes the next run from a
queue file, trains it with the team's default recipe (object keypoint reward x2, 100,003,840
environment steps), runs the official evaluator and moves on. It always takes the unstarted run
with the **lowest seed** first, so every episode gets seed 42 before any gets seed 43.

Queue file: `~/night/queue.txt`, one line per run:

```
NAME EP PARQUET SEED SCORE NJMAX
```

- `NAME`: `ep<EP>_kenC_s<SEED>` for scored, `ep<EP>_kenCpub_s<SEED>` for public.
- `SCORE`: `1` for public episodes (scores against public ground truth after evaluation), `0` for scored.
- `NJMAX`: `2048` for scored episodes **1, 10, 25** (their scenes overflow the default contact
  buffer), otherwise `1024`.

As soon as an episode's scene is ready, append **all** of its seeds at once:

```bash
add_runs() {  # add_runs <ns> <ep> <seeds...>
  local NS=$1 EP=$2; shift 2
  local E6=$(printf %06d $EP)
  local PQ=$T/baseline/reconstruction/data/outputs/load_retarget/episode_$E6/${NS}_attach/assets/human_motion_data/ego_recon/processed/sequence_id=ep${EP}_${NS}_attach/robot_name=sharpa_wave
  [ -d "$PQ" ] || { echo "ep$EP: scene not ready"; return 1; }
  local TAG=kenC SCORE=0 NJ=1024
  [ "$NS" = ken_c_public ] && TAG=kenCpub && SCORE=1
  case $EP in 1|10|25) [ "$NS" = ken_c_scored ] && NJ=2048 ;; esac
  for S in "$@"; do echo "ep${EP}_${TAG}_s$S $EP $PQ $S $SCORE $NJ" >> ~/night/queue.txt; done
}
add_runs ken_c_scored 14 42 43 44      # scored: seeds 42 43 44
add_runs ken_c_public 13 42 43         # public: seeds 42 43
```

Start the workers once, in a `tmux` session so they survive a closed terminal, with the GPU ids
that are free for training:

```bash
tmux new -s train
cd $T && mkdir -p ~/night/runs
RUNS=~/night/runs tools/track3/jobs/gpu_queue.sh ~/night/queue.txt 4 5 6 7 2>&1 | tee -a ~/night/queue.log
```

When reconstruction frees more GPUs, start a **second** queue process on the same queue file with
those ids (in another tmux window); the workers share the queue safely:

```bash
RUNS=~/night/runs tools/track3/jobs/gpu_queue.sh ~/night/queue.txt 0 1 2 3 2>&1 | tee -a ~/night/queue2.log
```

Workers wait for new lines when the queue is empty. When everything is queued and done, stop them
with `touch ~/night/queue.txt.stop`.

### 6.2 What to watch (check every ~30 minutes)

```bash

```

### 6.3 Expected numbers

- One run = 100,003,840 environment steps, then evaluation (a few minutes). The log line
  `train exit=0 minutes=N` gives the training time; multiply by the remaining runs / GPUs to see
  whether all seeds fit before the machine goes away. If not, delete the lines of the lowest
  priority (section 0) from `~/night/queue.txt` before a worker reaches them.
- `own-reference add_auc` is the policy against its own reconstruction (0 to 1). Anything from
  0.1 to 1.0 is normal; it is used tomorrow to pick seeds.

### 6.4 When something goes wrong

| Symptom | Do this |
|---|---|
| `train exit=` non-zero, `FAILED` file | Look at the end of `~/night/runs/<NAME>/train.log`. Out of GPU memory: rerun with NJMAX 1024 (if it was 2048). Otherwise note it in section 9 |
| `nefc_overflow_lines=` above 0 | Contacts overflowed. The run still counts. If time allows, queue it again with NJMAX 2048 under a new name `..._nj2048` |
| Rerun a failed or killed run | Delete its line from `~/night/queue.txt.taken`; a worker picks it up again and resumes from its newest saved state |
| Worker process died | Start `gpu_queue.sh` again with the same queue file and GPU ids; finished runs are skipped |
| A scene fails to build | Note it with the log tail (section 9); continue with other episodes |

## 9. Final report (write it, upload it with the outbox, and paste it to Ken)

Save as `~/night/outbox/REPORT.md` before the last upload:

3. **Run table**, one row per run, made with:
   ```bash
   cd ~/night/runs; for R in */; do N=${R%/}; E=$(echo $N | sed -E 's/^ep([0-9]+)_.*/\1/')
     J=$N/results/episode_$(printf %06d $E).json

   ```
