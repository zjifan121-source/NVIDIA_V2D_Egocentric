\subsection{Provenance of the submitted files}
\label{app:provenance}
The counted scores are the team's best public submission per board at the close (AUC 0.77970, SP-SR 0.95, MP-SR 0.65, RPE 3.86589\,cm, MPPE 3.28089\,cm, CD-O 0.32243\,cm; rank sum 81), produced by the team's final uploads (single-episode swaps and best-of-seed re-draws on the bob1 base). Every submitted file carries the kit's provenance columns on each row: the code commit URL, the sha256 of the evaluation script and evaluation code, of the packer and of the uploader, and the sha256 of the policy checkpoint that produced the episode; for the reconstruction line's six-board base file (sha256 \texttt{c8fcd7df\ldots}, Kaggle 57978563: bob1 with ep1 T2, ep3 T5, ep5 T8, ep8 T6), whose rows the final uploads share for every episode they did not replace, these are evaluation script \texttt{160d24f5\ldots}, evaluation code \texttt{b1b3ebe3\ldots}, packer \texttt{49b13052\ldots}, uploader \texttt{d31d4a7c\ldots} (evaluator at FlashCHORD revision \texttt{8c778f90}).
